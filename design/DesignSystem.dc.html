Material 3 mapping

Built on darkColorScheme() so stock M3 components (NavigationBar, ModalBottomSheet, ExtendedFloatingActionButton, SegmentedButton, Snackbar) inherit the look; module hues and data tokens live in a LifeColors CompositionLocal. Dynamic color is off — the brand is the palette.

darkColorScheme(
  primary          = Volt,        // #D3F36B
  onPrimary        = Graphite0,   // #0A0B0D
  background       = Graphite0,
  surface          = Graphite0,
  surfaceContainer = Graphite1,   // #121316
  surfaceContainerHigh = Graphite2, // #191A1E
  outlineVariant   = Hairline,    // #1F2125
  onSurface        = Ink,         // #EDEEF0
  onSurfaceVariant = InkMuted,    // #A1A4AB
)
